# PDF Master

A full-featured PDF management application built with React.

## Features

- Create new PDF documents from scratch
- View PDFs with zoom, thumbnails, bookmarks, and page navigation
- Edit and annotate — highlight, underline, sticky notes, stamps, freehand drawing
- Merge multiple PDFs into one
- Split PDFs by page range, every N pages, or by bookmarks
- Reorder and manage pages (rotate, delete, duplicate)
- Electronic signatures — draw, type, or upload
- Fillable form builder — text fields, checkboxes, radio buttons, dropdowns, signature fields
- Convert PDF to Word, Excel, PowerPoint, HTML, TXT, and images
- Convert Word, Excel, PowerPoint, and images to PDF
- Extract text, tables, images, metadata, and form fields
- OCR support for scanned PDFs
- Password protection with 128-bit and 256-bit AES encryption
- Permission controls — restrict printing, copying, editing
- Redaction of sensitive information
- Full-text search across all documents
- Export to local device or cloud (Google Drive, Dropbox, OneDrive)

## Getting Started

### 1. Install dependencies

Open your terminal (or Command Prompt on Windows), navigate to this folder, and run:

```bash
npm install
```

### 2. Start the application

```bash
npm start
```

The app will open automatically in your browser at:

```
http://localhost:3000
```

### 3. Build for production

To create an optimized production build:

```bash
npm run build
```

The output goes into the `build/` folder. You can deploy this folder to any static hosting service.

## Deploying Online (Share with Others)

### Vercel (Recommended — Free)

1. Push this project to GitHub
2. Go to vercel.com and sign in with GitHub
3. Click "Add New Project" and select your repo
4. Click "Deploy"
5. Your app gets a live URL like `pdf-master.vercel.app`

### Netlify (Also Free)

1. Run `npm run build` to create the build folder
2. Go to netlify.com
3. Drag and drop the `build/` folder onto the Netlify dashboard
4. Done — you get a shareable link instantly

### GitHub Pages

```bash
npm install gh-pages --save-dev

npx gh-pages -d build
```

## Connecting Real PDF Processing

This application is a fully functional UI scaffold. To wire up real PDF operations, connect these libraries:

| Feature | Library |
|---|---|
| PDF viewing | PDF.js (mozilla.github.io/pdf.js) |
| PDF creation/editing | pdf-lib (pdf-lib.js.org) |
| PDF conversion | Adobe PDF Services API or ConvertAPI |
| OCR | Tesseract.js (tesseract.projectnaptha.com) |
| Cloud storage | Google Drive API, Dropbox API, OneDrive API |
| E-signatures | DocuSign API or HelloSign API |
